# PhotoDiary Android App

A simple Android starter app built with Kotlin + Jetpack Compose for saving diary entries with a photo label.

## Features

- Create diary entries with title, note, and photo label/URI.
- Displays entries in reverse chronological order.
- Material 3 UI.

## Run

1. Open the project in Android Studio (Giraffe+ / Hedgehog+).
2. Sync Gradle.
3. Run the `app` configuration on an emulator or Android device.
